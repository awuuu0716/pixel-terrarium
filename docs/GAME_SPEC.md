## 1 遊戲定位與範圍

### 1.1 遊戲概念

玩家照顧一座玻璃瓶中的像素森林，放入植物與動物，透過天氣及日照調整環境，觀察生長、覓食、繁殖與死亡。畫面採固定微俯視的 2.5D 呈現，將平面的像素圖像依遠近投影、縮放與遮擋。

遊戲沒有勝負、關卡結算或通關條件。玩家可以持續觀察，也可以在生態衰退後補種植物、加入居民，或重新建立森林。這是一套療癒用途的簡化模擬，並非真實生態模型。

### 1.2 功能邊界

| 類別 | 已實作內容 |
| --- | --- |
| 植物 | 苔蘚、蕨類、小樹；成長、健康、散播與死亡 |
| 動物 | 小兔、蝸牛；散步、覓食、能量、配對繁殖與死亡 |
| 環境 | 晴天、下雨、夜晚；全域土壤濕度與日照 |
| 操作 | 放置、觀察、暫停、1×／2×／4×、天氣切換、日照調整 |
| 紀錄 | 3 個里程碑、事件日記、本機自動存檔、PNG 照片 |
| 願望與資源 | 5 個串連願望、一次性獎勵、森之露自動累積 |
| 佈置 | 3 件可購買、擺放、免費重擺與收回的裝飾 |
| 呈現 | 像素場景、前後遮擋、落地陰影、輕微視差、環境動畫、合成音效 |

生物放置與天氣操作仍免費；裝飾使用森之露購買。沒有帳號、雲端存檔、多人模式、生物拖移或生物單體刪除功能。裝飾從商店重新選位置，並非直接拖曳。

## 2 核心玩法與新手流程

### 2.1 核心循環

```mermaid
flowchart LR
  A[放入植物與居民] --> B[調整天氣與日照]
  B --> C[植物成長與動物覓食]
  C --> D[散播種子與配對繁殖]
  D --> E[觀察濕度 能量 日記與里程碑]
  E --> B
  E --> A
```

植物同時是景觀與動物的食物。動物進食會消耗植物大小；植物透過適當的光照、濕度與健康恢復生長。玩家的主要決策是維持食物供應與環境條件，而非直接操控居民。

### 2.2 新手操作流程

1. 開啟遊戲。若目前瀏覽器與網址有有效存檔，載入原森林；否則建立預設森林。
2. 先查看「森林的呼吸」，確認植物數量、居民數量、土壤濕度與生態活力。
3. 選擇苔蘚、蕨類或小樹，在瓶內綠色地面點一下，決定左右與前後位置。
4. 選擇小兔或蝸牛，再點地面加入居民。加入不消耗資源，但受容量限制。
5. 乾燥時切到下雨；水分充足時切回晴天。天氣會持續生效，直到玩家再次切換。
6. 使用「觀察」點選植物或動物，查看健康、能量、年齡與動物狀態。
7. 想欣賞夜景時切到夜晚；至少有 5 株植物時可看到螢火蟲。
8. 使用暫停或速度按鈕調整節奏，也可以保存目前場景的 PNG 照片。

### 2.3 建議玩法

- 初期維持足夠植物，再逐步增加動物，避免食物供應不足。
- 苔蘚生長係數最高；蕨類的食物轉換係數最高。所有植物都能被兩種動物食用。
- 可把約 45% 至 75% 濕度作為照顧時的操作區間；這也是既有長時間照顧測試使用的切換方式，並非保證永續的遊戲規則。
- 想促成繁殖，需同種動物、足夠能量、冷卻結束、合適濕度與至少 5 株植物。
- 4× 會同步加速乾燥、飢餓與繁殖冷卻；離開前可暫停。關閉或隱藏頁面後不進行離線演算。

### 3.2 放置與觀察

- 初始工具為「觀察」。
- 選擇物種後，滑鼠移到有效地面會顯示半透明預覽，點擊即加入一個物件。
- 預覽代表放置位置與物種；預覽植物大小固定為 `0.55`，實際新增大小會隨機決定。
- 可放置範圍僅限綠色地面。天空、土壤剖面與瓶外會出現提示，不增加物件。
- 暫停時仍可放置、觀察、切換天氣及拍照；生長與移動需恢復模擬才繼續。
- 物件可以重疊放置，沒有間距、占位或碰撞限制。
- 觀察模式依前後繪製順序挑選最前方符合命中範圍的生物。
- 點到空白處會取消選取並關閉資訊卡；關閉卡片後，焦點回到畫布。
- 被選取物件死亡或不再存在時，資訊卡會隱藏。

### 3.3 資訊卡內容

| 對象 | 欄位 |
| --- | --- |
| 植物 | 物種名稱、成長百分比、健康百分比、在森林的第幾天 |
| 動物 | 個體名稱、物種、能量百分比、目前狀態、在森林的第幾天 |

成長百分比為 `round(size / 1.35 × 100)`；個體天數為 `floor(age / 120) + 1`。天數是加入後的模擬時間顯示，不是動物壽命限制。

### 3.4 鍵盤與觸控

| 操作 | 行為 |
| --- | --- |
| Tab | 透過標準焦點順序進入按鈕、滑桿及畫布 |
| 方向鍵，放置模式 | 左右每次移動 8 個世界座標單位；前後每次移動 3 個世界深度單位，限制在地面內 |
| 方向鍵，觀察模式 | 每次移動 6 個邏輯畫面單位，可移到樹冠高度 |
| Enter 或空白鍵 | 在目前游標位置執行放置或觀察，並阻止該按鍵的預設捲動 |
| 首次鍵盤操作 | 游標回到世界座標 `(240, 221)` 的投影位置，視差歸零 |
| 觸控點擊 | 依當前工具放置或觀察；觸控不啟動滑鼠視差 |

觀察模式的鍵盤游標限制在邏輯畫面 `x = 55～425`、`y = 80～250`；滑鼠與觸控先通過 `x = 52～428`、`y = 72～264` 的互動外框，再執行細部命中判定。

### 3.5 版面與無障礙

- 桌面版以場景及右側資訊欄呈現；寬度不超過 850 px 時改為單欄主場景，下方排列資訊面板。
- 寬度不超過 540 px 時，物種按鈕排列為每列 3 個，資訊面板採單欄。
- 畫布具有焦點及操作文字說明；切換按鈕使用 `aria-pressed`；通知使用 `role="status"`。
- `prefers-reduced-motion: reduce` 會停住裝飾動畫時鐘、關閉視差，天氣配色立即切換；生態演算仍繼續。
- 上述為已實作支援，不能視為已完成行動裝置或螢幕閱讀器的完整驗證。

## 5 時間與更新流程

### 5.1 時間定義

| 項目 | 規格 |
| --- | --- |
| 模擬步長 | 固定 `0.1` 模擬秒 |
| 引擎單次步長防護 | `step()` 將傳入的 `dt` 限制在 `[0, 1]` |
| 一個遊戲日 | 120 模擬秒 |
| 1×／2×／4× | 在前景順暢執行時，每日約為 120／60／30 真實秒 |
| 畫面更新 | `requestAnimationFrame` |
| 每幀時間上限 | 真實時間差最多計入 `0.1` 秒，長時間卡頓不完整補算 |
| 資訊面板更新 | 累積時間超過 `0.4` 秒時更新 |
| 自動存檔 | 可見頁面的累積時間超過 `5` 秒時觸發 |
| 裝飾動畫 | 依 `min(模擬倍速, 2)` 推進，最高 2× |

「約 5 秒存檔」與 UI 更新使用每幀截斷後的時間，不受 1×／2×／4× 影響；嚴重卡頓時可能比真實 5 秒更久。暫停時仍更新介面並執行自動存檔。

### 5.2 每個模擬步驟

1. 增加世界時間，依天氣計算有效光照並更新全域濕度。
2. 依植物陣列順序增加年齡、更新健康與大小、處理散播計時及死亡。
3. 依動物陣列順序更新年齡與計時器、扣除能量、搜尋食物、進食或移動、嘗試繁殖、處理死亡。
4. 檢查夜晚里程碑。

生物迴圈使用當次陣列的淺複本：剛散播的植物不在同一植物迴圈內再次成長，但可被後續動物迴圈當作食物；剛出生的動物不在同一動物迴圈內再次更新。數值與資源是依順序修改，並非所有個體完全同時結算。

### 5.3 天數與時段顯示

```text
遊戲天數 = floor(time / 120) + 1
個體天數 = floor(age / 120) + 1
```

晴天時，當日第 0～29、30～59、60～89、90～119 秒分別顯示清晨、上午、午後、黃昏。雨天固定顯示「雨天」，夜晚固定顯示「夜晚」。

**時段標籤不會改變天氣或光照。沒有自動日夜循環，也沒有自動天氣輪替。**

### 5.4 暫停與離開頁面

- 暫停：停止世界演算、裝飾動畫時鐘與視差插值。介面、手動操作、天氣配色過渡及存檔仍可進行；環境音不因暫停而自動關閉。
- 頁面隱藏：停止演算與場景更新、儲存世界、暫停音訊，並清除時間追補用的累積值。
- 頁面恢復可見：從既有世界繼續；若之前開啟音訊，嘗試恢復播放。
- 關閉頁面：嘗試存檔，不計算離線生長、飢餓或繁殖。

## 6 天氣與環境

### 6.1 計算符號

後續公式中的 `dt` 為模擬秒；`clamp(v, a, b)` 表示把 `v` 限制在 `[a, b]`。隨機值 `r` 來自 `[0, 1)`，因此由隨機值推導的區間通常不包含上限。

| 符號 | 意義 |
| --- | --- |
| `M` | 土壤濕度，範圍 `[0, 100]` |
| `S` | 日照滑桿數值，範圍 `[10, 100]` |
| `L` | 有效光照係數 |
| `N` | 當次更新濕度時的植物總數 |
| `F` | 濕度對植物成長的係數 |

### 6.2 三種天氣

| 天氣 | 有效光照 L | 濕度變化／模擬秒 | 動物影響 |
| --- | --- | --- | --- |
| 晴天 | `S / 100` | `-0.028 - L × 0.055 - N × 0.0006` | 基準速度與飢餓 |
| 下雨 | `(S / 100) × 0.48` | `+0.48` | 蝸牛速度乘以 1.8；飢餓不變 |
| 夜晚 | 固定 `0.06` | `-0.028 - L × 0.055 - N × 0.0006` | 全部動物速度乘以 0.7，飢餓乘以 0.6 |

```text
M_new = clamp(M + dt × 對應的濕度變化, 0, 100)
F = clamp(1 - abs(M_new - 65) / 70, 0.05, 1)
```

夜晚日照滑桿停用，原本的滑桿值保留；返回晴天或雨天後再使用該數值。切換天氣時，模擬立即採用新規則，畫面配色則逐漸變化。

所有植物共用同一個濕度與光照值。樹蔭、池塘、物件前後位置及玻璃反光不會改變局部生長條件。

## 7 植物系統

### 7.1 物種參數

| 物種 | 代碼 | 生長係數 growth | 食物係數 food | 成長公式的 wetNeed |
| --- | --- | ---: | ---: | ---: |
| 苔蘚 | `moss` | 0.0028 | 0.9 | 0.4 |
| 蕨類 | `fern` | 0.0018 | 1.1 | 0.65 |
| 小樹 | `tree` | 0.0009 | 0.5 | 0.4 |

`wetNeed` 是成長公式中的加成係數，不是植物獨立耗水量，也不是最低存活濕度。

### 7.2 新增與幼苗

| 欄位 | 手動新增 | 自然散播 |
| --- | --- | --- |
| age | 0 | 0 |
| size | `0.35 + r × 0.25`，即 `[0.35, 0.60)` | 0.2 |
| health | 95 | 95 |
| seed | `r × 100`，控制外觀 | 同左 |
| seedTimer | `45 + r × 100` 模擬秒 | 同左 |

### 7.3 健康與成長

健康先更新，再以更新後的健康與濕度計算成長。

| 濕度條件 | 健康變化／模擬秒 |
| --- | ---: |
| `M < 15` | -0.18 |
| `M > 96` | -0.06 |
| `15 ≤ M ≤ 96` | +0.07 |

```text
health_new = clamp(health + dt × 健康變化, 0, 100)
size_new = clamp(
  size + dt × growth × L × F × (health_new / 100) × (M / 100 + wetNeed),
  0.08,
  1.35
)
```

- 夜晚仍有微量成長，因為 `L = 0.06`，不是零。
- 被動物吃掉的大小可透過後續成長恢復。
- 健康小於 35 時降低繪圖透明度；健康到 0 時移除植物並記錄死亡事件。
- 植物不會因年齡自動死亡，也沒有獨立的季節或生命週期階段。

### 7.4 自然散播

每次更新減少 `seedTimer`。計時器到 0 或以下時，先重設為 `100 + r × 160` 模擬秒，再檢查以下條件：

1. `size > 0.72`。
2. `health > 65`。
3. `M > 28`。
4. 全部植物總數 `< 45`。
5. 當次隨機判定 `< 0.65`，即符合前述條件後有 65% 機率成功。

成功時新增同物種幼苗，並記錄發芽事件：

```text
child.x = clamp(parent.x + (r - 0.5) × 65, 66, 414)
child.y = 205 + r × 31
```

左右位置在母株附近隨機決定，但深度可以落在幾乎整個地面；目前不是以母株為中心的完整二維散播半徑。失敗也會消耗這一次散播機會，需等下次計時到期。

## 8 動物系統

### 8.1 物種參數

| 物種 | 代碼 | 基準速度／模擬秒 | 基準能量消耗／模擬秒 | 特殊規則 |
| --- | --- | ---: | ---: | --- |
| 小兔 | `rabbit` | 9 | 0.15 | 移動時呈現跳躍動畫 |
| 蝸牛 | `snail` | 2.4 | 0.075 | 雨天速度為 4.32 |

速度使用下述地面距離單位；能量消耗是能量值的扣減量，不是乘上目前能量的百分比。夜晚小兔速度為 6.3、蝸牛為 1.68；對應能量消耗為 0.09 與 0.045。

### 8.2 初始化與名稱

| 欄位 | 手動新增 | 配對出生 |
| --- | --- | --- |
| age | 0 | 0 |
| energy | 85 | 65 |
| breed 冷卻 | `50 + r × 40` 秒 | 150 秒 |
| wander 計時 | 0 | 0 |
| 方向 dir | 隨機 -1 或 1 | 同左 |
| 目標座標 | 新增時傳入的位置 | 同左 |
| 初始狀態文字 | 散步中 | 散步中 |

名稱從物種名單隨機選取，可重複，沒有改名功能：

- 小兔：麻糬、米粒、雪球、豆花、奶酥、小麥、棉花、布丁。
- 蝸牛：慢慢、露珠、阿捲、抹茶、小雨、栗子、圈圈、青苔。

`age < 35` 模擬秒時，動物圖像縮為 0.8 倍。此顯示規則也適用於初始及手動新增動物，不只適用於配對出生的幼體。

### 8.3 地面距離與移動

```text
D(a, b) = sqrt((a.x - b.x)^2 + ((a.y - b.y) × 3)^2)
```

世界深度 1 單位視為左右距離的 3 單位；覓食、移動及配對距離使用同一度量。

- 到目標的距離 `D > 3`，且狀態不是「吃點心中」時才移動。
- 每步距離為 `min(D, speed × dt × 天氣速度倍率)`，不超過目標。
- 依地面距離正規化後移動；Y 方向換回世界座標時除以 3。
- 水平差異足夠大時，依左右方向更新朝向；沒有正面或背面專用精靈圖。
- 不計算避障、碰撞、道路或繞行；池塘、石頭、植物及動物都不阻擋移動。

### 8.4 飢餓與食物選擇

每步先扣除能量：

```text
energy = clamp(energy - dt × hunger × (夜晚 ? 0.6 : 1), 0, 100)
```

能量 `< 88` 時，搜尋所有符合 `size ≥ 0.2` 且 `health ≥ 15` 的植物，選地面距離最近者。兩種動物都能吃三種植物，沒有物種食性或偏好，也沒有最大搜尋距離；同距離時保留先遇到的植物。

找到食物後，把目標設為植物位置：距離 `< 8` 時進食，否則標示「尋找點心」並朝目標移動。

### 8.5 進食計算

```text
portion = min(max(0, plant.size - 0.12), dt × 0.005)
plant.size = plant.size - portion
animal.energy = clamp(animal.energy + portion × 520 × plant.food, 0, 100)
```

| 食物 | 持續進食時的理論能量增加／模擬秒 |
| --- | ---: |
| 苔蘚 | 2.34 |
| 蕨類 | 2.86 |
| 小樹 | 1.30 |

表內為進食增加量，尚未扣除同一步的飢餓消耗；也未考慮植物不夠大、能量上限與重新選擇食物等限制。

`0.12` 是單次消耗公式的保護下限；實際上植物一旦低於 `0.2`，下一步就不再符合食物條件。進食減少植物大小，不直接扣除健康，也不直接觸發植物死亡。

### 8.6 散步與狀態文字

沒有找到食物且 `wander ≤ 0` 時，產生新的散步目標：

```text
targetX = 66 + r × 348
targetY = 207 + r × 29
wander = 5 + r × 14 秒
```

| 狀態文字 | 主要觸發條件 |
| --- | --- |
| 散步中 | 非夜晚產生新的散步目標，或剛建立個體 |
| 月下散步 | 夜晚產生新的散步目標 |
| 尋找點心 | 已找到可食植物，但距離尚未小於 8 |
| 吃點心中 | 距離食物小於 8，執行進食 |
| 發呆中 | 無食物且當步未進行移動，非夜晚 |
| 打盹中 | 無食物且當步未進行移動，夜晚 |

狀態文字由條件分支更新，不是獨立的完整有限狀態機；例如切換天氣不會立即改寫所有居民既有的散步文字。發呆與打盹不額外回復能量。

### 8.7 配對繁殖

主動發起繁殖的個體必須同時符合：

- `energy > 83`。
- `breed ≤ 0`。
- 全部植物數 `≥ 5`。
- `25 < M < 94`。
- 全部動物數 `< 18`。

接著依動物陣列順序找到第一隻符合以下條件的同伴：

- 不是自己，且物種相同。
- 同伴 `energy > 75`、`breed ≤ 0`。
- 與發起者的地面距離 `< 75`。

成功時：

1. 在發起者的 `(x + 8, y)` 新增同種幼體，位置再套用新增物件邊界限制。
2. 發起者能量減少 20，同伴減少 15。
3. 雙方繁殖冷卻設為 160 模擬秒；新生個體冷卻為 150 秒、能量為 65。
4. `births` 增加 1，解鎖家庭里程碑，新增出生日記。

繁殖沒有額外機率判定，也沒有性別、懷孕期、遺傳或獨立的成年年齡門檻；不會主動為繁殖搜尋或追逐同伴。是否能繁殖取決於當步位置、能量與冷卻條件。

### 8.8 死亡

當步處理完進食、移動及繁殖後，若能量 `≤ 0`，移除動物、記錄事件，並使全域濕度增加 3，最高為 100。

因死亡檢查在進食之後，當步能量先降到 0 的動物若立即取得食物，仍可能回復而存活。年齡不造成自然死亡；死亡判定只看能量。

## 9 活力與照顧提示

### 9.1 活力公式

```text
moistureScore = 100 - abs(M - 65) × 1.2
healthScore = 有植物 ? 植物平均健康 : 0
energyScore = 有動物 ? 動物平均能量 : 65
vitality = round(clamp(
  moistureScore × 0.3 + healthScore × 0.4 + energyScore × 0.3,
  0, 100
))
```

植物與動物皆為空時，直接回傳活力 0。活力是 UI 摘要指標，不會再反過來影響生長、繁殖或死亡。

| 活力值 | 文字 |
| --- | --- |
| `> 75` | 蓬勃生長 |
| `> 50` 且 `≤ 75` | 安穩生活 |
| `≤ 50` | 需要照顧 |

### 9.2 照顧提示優先順序

只顯示第一個符合的條件：

1. 濕度 `< 28`：提醒下雨。
2. 濕度 `> 90`：提醒換回晴天。
3. 植物數 `< 5`：提醒增加植物。
4. 任一動物能量 `< 30`：提醒附近補種苔蘚。
5. 其餘：顯示一般陪伴文字。

提示門檻、植物受傷門檻與繁殖濕度門檻各自獨立。動物圖像上的低能量警示則在 `energy < 25` 時出現。

## 10 里程碑與日記

### 10.1 里程碑

| 顯示名稱 | 代碼 | 條件 |
| --- | --- | --- |
| 一片小森林 | `garden` | 新增物件時檢查植物數 `≥ 12` |
| 新生命報到 | `family` | 成功發生一次動物配對繁殖 |
| 夜裡有微光 | `night` | 模擬步驟結束時為夜晚，且植物數 `≥ 5` |

里程碑一旦解鎖便保存，不會因生物死亡或切換天氣撤銷；重建森林才重設。手動加入幼齡動物不會解鎖繁殖里程碑。

螢火蟲的畫面條件使用當前夜晚配色權重與植物數，不以里程碑是否已解鎖為開關。因此暫停時切到夜晚也可呈現螢火蟲，但里程碑需等模擬恢復、執行下一步才檢查。

### 10.2 日記事件

紀錄類型包含世界建立、玩家新增物種、切換天氣、自然發芽、動物出生、植物死亡、動物死亡、森林里程碑與夜晚發現。

- 每筆資料為 `{ time, text }`，`time` 是事件發生時的模擬時間。
- 新事件放在最前面，最多保存最近 20 筆；介面只顯示最近 3 筆。
- 暫停、倍速、調整日照、拍照及音效切換不新增日記事件。
- 日記時間顯示為 `DAY floor(time / 120) + 1`，以及 `floor((time % 120) / 2) MIN`。
- `MIN` 是把每日 120 模擬秒映射成 0～59 的顯示刻度，不代表真實分鐘。

## 11 2.5D 場景與互動判定

### 11.1 座標與投影

| 層級 | 規格 |
| --- | --- |
| 世界座標 | 保留 v1 格式，地面 X 為 62～418、Y 為 205～237 |
| 邏輯畫面 | 480 × 320 |
| 主畫布 | 960 × 640，CSS 保持 3:2 比例隨版面縮放 |
| 深度方向 | Y 越大越靠近觀察者 |
| 遠近縮放 | 地面後緣 0.82 倍、前緣 0.98 倍，再乘上個體大小 |

```text
depth = (worldY - 205) / 32
scale = 0.82 + depth × 0.16
screenX = 240 + (worldX - 240) × scale + viewX × (depth - 0.5)
screenY = 178 + depth × 66 + viewY × (depth - 0.5)
```

滑鼠與觸控位置先依畫布實際尺寸換算到 480 × 320 邏輯畫面，再以反投影轉回世界座標。地面判定容許 `1e-8` 的浮點誤差，最後限制回合法邊界。

### 11.2 繪製層次

大致依序繪製：桌面背景與瓶底投影、瓶內天空與遠景、光束或星月、土壤剖面與地面、道路與池塘、依深度排序的生物與石頭、前景小花、天氣粒子、玻璃邊緣與反光、瓶塞與標籤。

- 生物與石頭按世界 `y` 由小到大繪製；同一深度以 `id` 由小到大決定順序。
- 半透明放置預覽也加入深度排序，表現它與既有生物的前後關係。
- 落地陰影依個體位置與大小繪製；兔子跳躍時陰影留在地面。
- 植物實際繪圖大小最低採 `0.28`，使幼苗仍可看見與選取；模擬中的 `size` 可低於此值。
- 玻璃、土壤厚度、光束、影子、星月與粒子都是視覺表現，不參與物理或局部生態計算。

### 11.3 命中判定

- 從生物的反向繪製順序檢查，優先命中較前面的物件；同深度優先命中較大 ID。
- 依物種尺寸、個體大小與景深縮放建立範圍，附加 2 個邏輯畫面單位的容差。
- 小樹額外使用樹幹區域與多個樹冠橢圓近似，避免把樹幹旁大片空白都視為樹木。
- 其餘物種使用近似包圍範圍，不是逐像素透明度檢查。
- 石頭及池塘不可觀察；它們也不加入生物點選候選。選取的黃色地面標記與箭頭不改變模擬。

### 11.4 動畫與視差

| 對象 | 呈現 |
| --- | --- |
| 小樹與蕨類 | 葉冠或葉片搖動；樹冠使用快取圖像 |
| 小兔 | 散步或找食物時跳躍，待機呼吸、眨眼，進食時顯示食物 |
| 蝸牛 | 觸角擺動及身體微動 |
| 池塘 | 擴散漣漪與亮面 |
| 晴天 | 光束、微粒、2 隻裝飾蝴蝶 |
| 雨天 | 80 個雨滴樣本依深度落下，近地面顯示濺水 |
| 夜晚 | 星月；植物數至少 5 時顯示 14 個螢火蟲樣本 |

只有滑鼠、觀察工具、非暫停且未啟用減少動態時，指標移動才設定視差目標。目標由指標相對畫布中心的位置計算，最大約為 `viewX ±3`、`viewY ±1.5`；每個景物再依深度取得較小的實際位移。

視差與天氣配色使用 `ease = 1 - exp(-elapsed × 5)` 插值。天氣配色可在暫停時繼續過渡。鍵盤操作會把相機歸零；觸控不產生新的視差目標。

## 13 資料與存檔

### 13.1 儲存機制

- 使用瀏覽器 `localStorage`，鍵名為 `little-forest-v1`，內容為世界物件的 JSON。
- 可見頁面約每 5 秒存檔；新增物件、切換天氣、完成日照調整、確認重建、頁面隱藏及 `pagehide` 時也嘗試保存。
- 模擬中的出生與死亡不各自立即觸發 `save()`，由後續定期或其他儲存時機保存。
- 2.5D 仍使用版本 1 的世界座標與欄位，可直接讀取舊版有效存檔。
- 存檔限同一瀏覽器設定檔與 origin。協定、主機或連接埠不同，便是不同的儲存空間。
- 無雲端同步、跨裝置同步、匯入匯出介面或多存檔槽。

主要數值檢查包括：

| 項目 | 接受範圍 |
| --- | --- |

| 濕度、健康、能量 | 0～100 |

| nextId | 1～10⁹ |
| births | 0～10⁹ |
| 個體 ID | 1～nextId−1，且不可重複 |
| 儲存的個體位置 | X 為 50～430，Y 為 200～240，較新增範圍寬 |
| 植物大小 | 0.08～1.35 |
| 動物目標 | X 為 50～440，Y 為 200～245 |
| 動物方向 | -1 或 1 |
| 動物名稱／狀態 | 字串，長度分別最多 20／30 |

`seed`、計時器須為有限數值。事件只保留時間為有限數值、文字為字串且長度小於 180 的項目，截取前 20 筆；里程碑值以嚴格的 `true` 還原。這是防止常見損毀的檢查，並非完整的惡意存檔驗證或防作弊系統。

- 世界主要資料不合法時回傳失敗，程式建立新森林；目前沒有損毀存檔備份或專屬復原畫面。
- `localStorage` 讀寫發生例外時，介面顯示無法存檔；世界仍可在記憶體中運作。
- 讀檔失敗後，新森林可能在後續自動存檔時覆寫原鍵值。

### 13.5 重新種一瓶

玩家先開啟確認視窗，可取消或確認。確認後重新建立預設世界、清除選取、清零模擬累積值、切回觀察工具並儲存；原世界與日記被取代。

願望、森之露、裝飾持有與擺放也隨新世界重設，確認文案明示這些範圍。

這個操作目前不重設暫停、倍速、音訊開關、裝飾動畫時鐘與視差。新世界的天氣重設為晴天，但配色會由現有視覺狀態逐漸切換。

## 16 目前限制與實作注意事項

1. **沒有自動日夜與天氣。** 天數、清晨與黃昏是標籤，玩家選的天氣會持續。
2. **沒有離線進度。** 頁面隱藏、關閉與長時間卡頓不會完整追補世界時間。
3. **不是完整 3D。** 使用 2D Canvas 投影與排序，沒有自由旋轉相機、真實光照、物理陰影或碰撞。
4. **環境是全域值。** 植物位置、池塘與樹蔭不影響局部濕度或日照。
5. **裝飾不等於生物。** 蝴蝶、螢火蟲、小花與遠景不占容量，不覓食、不繁殖。
6. **自然散播與手動上限不同。** 45 株是自然散播檢查門檻，65 株才是植物總容量。
7. **年齡主要用於顯示。** 沒有老死；動物繁殖沒有獨立成年判定，主要受冷卻與能量限制。
8. **植物健康與食物大小分離。** 進食只縮小植物，不直接降低健康；植物數量充足也不代表所有植物都可食。
9. **重建森林保留部分操作設定。** 暫停、倍速與音訊沒有隨世界一起重設。
10. **生物沒有個別管理與復原。** 不能移動、刪除或改名單一生物，也不能還原重建前的存檔。新裝飾可免費重擺／收回，取消重擺保留原位置。
11. **尚未處理多分頁協調。** 同 origin 的多個頁面各自模擬並寫入同一 localStorage 鍵，沒有互斥或 `storage` 事件同步。
12. **狀態與命中為近似實作。** 動物狀態文字不是完整狀態機；點選使用近似幾何範圍，未逐像素分析動畫與透明區域。
13. **存檔是盡力保存。** 儲存空間不可用、頁面突然終止或資料損毀都可能失去進度；沒有伺服器備份。
14. **森林可能衰退。** 長期乾旱、過濕或食物不足可以導致全部生物消失；遊戲仍允許玩家重新補種。

以上記錄現有範圍與行為，不構成新增功能或修正工作的承諾。

## 18 森林願望、森之露與裝飾

### 18.1 願望與證據

森林上方一次顯示一個願望、狀態、獎勵與主要操作。可收合內容，摘要與餘額仍保留；收合偏好不存檔。完成條件時等待玩家領取，只有當前願望能領，領取後前進；五個領完顯示完成與繼續佈置。

| 順序／代碼 | 名稱 | 永久達成條件 | 獎勵 |
| --- | --- | --- | --- |
| 1 `garden` | 準備一桌點心 | 植物曾達 12 株，或已有 garden 里程碑 | 25 |
| 2 `fed` | 居民開飯了 | 至少一次實際進食 portion > 0；不是只看狀態文字 | 15 |
| 3 `night` | 夜裡的微光 | 已有 night 里程碑（規則見第 10 節） | 15 |
| 4 `decorated` | 佈置我的森林 | 成功擺放至少一件已購裝飾 | 20 |
| 5 `family` | 新生命報到 | births > 0 或已有 family 里程碑；手動加入幼體不算 | 30 |

證據可以提前取得且不因植物減少、收回裝飾或切換天氣撤銷。舊存檔的既有里程碑與出生數補入證據；實際進食在新版本運轉時記錄。新局有 9 株植物，因此首願望通常補 3 株即可；植物已達容量的舊森林也可直接符合，不要求額外新增。

### 18.2 森之露

初始為 0，領獎立即增加。每個正時間模擬步驟結束時，以當步生物狀態計算並增加 `產率 × dt`；顯示向下取整，內部保留小數，總量上限 10 億。

| 來源 | 資格 | 每種計數上限 | 每隻／株每模擬秒 |
| --- | --- | --- | --- |
| 苔蘚、蕨類、小樹 | 健康 ≥ 65 | 每種 3 株 | 0.01 |
| 小兔、蝸牛 | 能量 ≥ 75 | 每種 2 位 | 0.02 |

所有來源合計最高每模擬秒 0.17，1× 每真實分鐘約 10.2；背景、暫停、關閉頁面不增加，2×／4× 同時加速模擬與產出。生長或飢餓會改變資格，所以 UI 速率是當下估計，並非固定保證。領獎總額 105；森之露只購買裝飾，不消耗動物能量，不限制免費照顧。

### 18.3 裝飾與操作

| 代碼 | 名稱 | 價格 |
| --- | --- | --- |
| `mushroom` | 蘑菇小燈 | 20 |
| `sign` | 林間木牌 | 35 |
| `path` | 石頭小徑 | 50 |

每款限持有一件。購買扣一次款、留在商店並改為可放置；不足時不可買並顯示差額。買下不等於已擺放。點「放進森林／重新擺放」關閉商店、切到裝飾工具並聚焦畫布。點綠色地面或用方向鍵加 Enter／空白鍵擺放，成功後回觀察。按 Esc、取消擺放或換工具不改變原擺放位置。

座標合法範圍 X 62～418、Y 205～237，沿用地面反投影；無效位置不扣款、不丟失物品。收回只移除座標，持有與願望證據保留，不退款。裝飾共用前後排序並包含於照片，不占 65／18 生物容量，也不影響覓食、碰撞或產率。觀察點選仍只針對生物，裝飾管理從商店進行。

### 18.4 v1 存檔擴充

沿用 `little-forest-v1` 與 `version: 1`，新增可選 `progression`：`dew`、`claimed`（已領願望 ID 陣列）、`evidence`（永久布林證據）、`owned`（裝飾持有布林）、`decorations`（各裝飾 `{x,y}`）。

讀檔時無新欄位則補預設；非有限餘額補 0、負數限制到 0、超額限制到上限，只保留認識的願望與裝飾。只有已持有且座標合法的裝飾會還原擺放；損毀擴充欄位局部修復，不因此清除有效的原森林。已領紀錄也補上對應證據，重整不重領。購買、領獎、擺放與收回立即嘗試存檔，其餘沿用定期保存。
