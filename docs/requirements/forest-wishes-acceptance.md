## 試玩情境

建議先不看下面的完整步驟，玩五分鐘，再回答：現在要做什麼？下一個想得到什麼？資源如何取得？

| 情境 | 操作 | 應觀察到的結果 |
| --- | --- | --- |
| 第一次進入 | 查看森林上方願望 | 清楚知道當前目標、進度、獎勵與可執行操作 |
| 首次回饋 | 依提示補種、完成願望並領取 | 得到足以購買第一件裝飾的森之露，下一願望出現 |
| 選擇與不足 | 打開佈置森林，比較三件裝飾 | 名稱、外觀、價格清楚；不足時提示還差多少 |
| 購買與佈置 | 買下裝飾，選擇放入森林並點地面 | 只扣一次款，場景出現裝飾；未放置前仍保有物品 |
| 無效位置與取消 | 嘗試瓶外、天空，或取消重擺 | 不遺失物品、不再次扣款，取消重擺保留原位置 |
| 重擺與收回 | 重新選位置，再收回 | 免費操作，收回後可再次放置 |
| 後續願望 | 觀察進食、切夜晚、佈置、照顧到自然出生 | 願望證據不因提早完成而消失，領獎不重複 |
| 自由觀察 | 收起願望、暫停 | 畫面保留必要摘要；暫停時森之露停止累積 |
| 存檔 | 重整本機試玩頁面 | 資源、領獎、裝飾持有與位置保留 |
| 鍵盤與窄版 | 用 Tab／Enter 操作；縮小視窗 | 目標、商店和放置可操作，焦點可辨認，無橫向溢出 |

不要為測試清除原有森林；本次會提供不同 origin 的試玩入口。只有願意清除這個試玩世界時，才測試「重新種一瓶」的確認與重置。

## 驗收回饋重點

1. 不看說明時是否知道下一步？在哪裡停住？
2. 第一件裝飾是否值得取得？三件之間有沒有選擇感？
3. 資源累積速度是否太快或太慢？有沒有被迫等待？
4. 願望是否打擾原本的療癒感？收起後是否足夠安靜？
5. 完成首次循環後，是否有下一個想追求的目標？
