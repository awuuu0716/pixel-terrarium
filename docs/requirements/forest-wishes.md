# 森林願望與輕量經濟：第一輪試玩

## 狀態與目標

2026-11-05 使用者授權規劃並安排 UIUX、RD 實作，階段完成後由使用者進行一輪驗收。狀態：第一輪實作與內部檢查完成，待使用者試玩驗收；尚未發布。PM 統一協調。

解決玩家不知道下一步做什麼、照顧後沒有期待的問題。第一輪以「照顧 → 獎勵 → 選擇裝飾 → 森林可見變化」為核心，目標是新玩家五分鐘內能完成一次循環。這是待試玩的設計目標，不是已證明的結果。

## 本輪範圍與決策

- 五個串連願望：補種食物、居民實際進食、夜間發現、首次佈置、自然出生。一次突出當前願望，顯示條件、進度、獎勵與操作提示，可收起；完成後有明確的領取與前進方式。
- 只用一種資源「森之露」。願望提供一次性獎勵；健康植物和吃飽居民隨模擬時間自動累積。相同物種產量有遞減或上限，多樣性具有價值；不需逐隻點擊收取。暫停與隱藏頁面不生產，倍速一致作用於模擬。
- 初次願望不依賴飢餓或隨機繁殖即可完成。第一筆獎勵足夠買至少一件裝飾；玩家可以選購或存錢。條件若先完成需保留證據，避免強迫重做或卡關。繁殖安排在後段並提示條件。
- 三件自然主題裝飾，價格不同；全部可預覽名稱、外觀、價格。各買一次，購買扣款、擁有狀態、餘額不足提示清楚。購買後選擇瓶內地面放置；可免費重擺／收回，不重複扣款。裝飾加入前後遮擋，不占生物容量、不影響覓食。
- 保留現有免費生物放置、天氣、照顧與生態玩法。新經濟不取代居民能量。沿用療癒風格，無期限、每日懲罰或付費貨幣。
- 沿用本機存檔。既有 v1 世界與里程碑保留，安全補上新進度；重整不重複發獎。重新種一瓶會清除資源、願望與裝飾，確認文案說清楚。
- 完成願望後提供清楚的完成狀態與仍可選購／佈置提示。舊存檔滿容量情境要有可完成的條件，不要求無法再新增的數量。
- 第一輪不擴張到新物種、完整圖鑑、新瓶型、離線收益或每日任務。夜間與出生保留既有里程碑／日記作為發現紀錄。

## 驗收條件

1. 新世界可見下一步、條件與獎勵；五分鐘內有可操作的首次獎勵與裝飾選擇。
2. 五個願望依規則前進，提前完成證據被保留，每個只領一次；重整、重複操作不重領。
3. 健康／飽足、多樣性與同種上限的產量符合明確數值；暫停、零時間與背景不憑空產出。
4. 三件裝飾皆可買、地面放置、重擺／收回；無效位置不消耗或丟失物品，餘額不可為負，重複購買不扣款。
5. 資源、願望、持有與擺放重整後保留；舊存檔仍保留居民、座標、日記與里程碑；損毀的新欄位不應毀掉有效森林。
6. 桌面與窄版流程清晰，鍵盤可選購和放置，觸控目標可用；焦點、成功／不足提示與減少動態可用。
7. 既有生態、容量、投影、照片、存檔流程保持可用；裝飾需出現在場景與照片。
8. 通過 npm run check、npm test、針對經濟／領獎／遷移／放置的必要測試，以及可用環境下的瀏覽器驗證。未完成的裝置測試明確列出。
